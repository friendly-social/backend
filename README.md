# Friendly

Backend repository for Friendly.

## Patches

Main git repository for backend is located under
[git.getfriend.ly](https://git.getfriend.ly/backend/about/). Development is
performed through sending patches to maintainers via Friendly itself.

Code is not a contribution. Code is a liability. GitHub is filled with AI-slop
that we don't really need in our projects. But we do need long-term
contributors, people who will drive vision of this project, etc.

If you are from outside and want to become a contributor (and maintainer later
on), you can contact main maintainer of this repo via
[friendly@y9san9.me](mailto:friendly@y9san9.me)

Internal development communication happens within Friendly itself, and you can
get there either via social graph and builtin Friendly features, or via invite
after contacting developers via email above.
